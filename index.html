CICIDS2017: End-to-End Intrusion Detection Pipeline

A full exploratory data analysis and three-stage machine learning pipeline built on the CICIDS2017 network traffic dataset — from raw packet-flow CSVs to a working detection and classification system.

99.9% Binary detection accuracy (benign vs. attack)
99.97% Attack-type classification accuracy
99.89% Combined detection & classification accuracy
  • Loaded and merged eight raw CICIDS2017 capture files, then cleaned column names, labels, and invalid/infinite values.
  • Ran a full EDA pass: class balance, attack behavior, port usage, packet-size patterns, timing behavior, and cross-feature correlation per attack category.
  • Engineered binary and multi-class targets, then built a three-stage model chain — attack detection, attack-type classification, and a combined detection-plus-classification model.
  • Handled severe class imbalance with sample weighting and evaluated every stage with precision, recall, F1-score, and full classification reports.
